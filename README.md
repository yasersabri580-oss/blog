# بلاگ — devecomix

نمونهٔ فارسی و راست‌به‌چپ بلاگ، خبر و فروشگاه، در یک فایل `index.html` با CSS و JavaScript داخلی؛ بدون بک‌اند.

- رمز بازدید: `devecomix`
- طراحی و مالکیت: **devecomix**
- سفارش: **0765220423**
- نوشتن، ویرایش و حذف مقاله، خبر و محصول؛ تصویر از دستگاه؛ پیش‌نویس و علاقه‌مندی‌ها
- ذخیرهٔ محتوا در `localStorage` همین مرورگر، خروجی JSON، اشتراک‌گذاری تلگرام، واتساپ، فیسبوک و دستگاه
- لینک مقاله‌های نمونه به همان مقاله اشاره می‌کند؛ مطالب ساخته‌شده توسط بازدیدکننده محلی هستند و لینک، آن محتوا را برای دیگران منتشر نمی‌کند.
- خرید و خبرنامه صرفاً نمایشی‌اند؛ پرداخت، ثبت سفارش خارجی یا ارسال ایمیل ندارند.

## استفاده

فایل `index.html` را در مرورگر باز کنید. برای دسترسی قابل‌اعتماد به حافظه و اشتراک‌گذاری، میزبانی HTTPS پیشنهاد می‌شود.

فونت و تصاویر نمونه از Google Fonts و Unsplash بارگیری می‌شوند؛ CSS و JavaScript داخل همین فایل هستند. بدون اینترنت فونت جایگزین استفاده می‌شود؛ تصاویر خارجی نیاز به اینترنت دارند.

## میزبانی رایگان GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

GitHub Pages برای ریپازیتوری خصوصی معمولاً به طرح پولی مناسب نیاز دارد. در GitHub Free می‌توان ریپازیتوری را عمومی کرد و Pages را فعال کرد.

## محدودیت رمز و مالکیت

رمز داخل JavaScript یک دروازهٔ نمایشی است و امنیت واقعی یا جلوگیری از مشاهده و کپی کد ایجاد نمی‌کند. محتوای سایت استاتیک در مرورگر دریافت می‌شود. پیام مالکیت اعلام حقوق طراحی است، نه قفل فنی کپی‌برداری. رمز را با ذخیرهٔ نشست حفظ نکرده‌ایم؛ هر بار باز کردن صفحه به ورود نیاز دارد.

داده‌ها به سرویس ما ارسال نمی‌شوند. با پاک‌کردن داده‌های مرورگر یا تغییر دامنه، نوشته‌های محلی در دسترس نخواهند بود؛ برای حفظ آن‌ها خروجی JSON بگیرید.
